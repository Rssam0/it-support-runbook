# Slow computer

1. Ask: since when? After an update or new program? Slow everywhere or one app?
2. Check usage: Task Manager (Windows) or `top` / `htop` (Linux). Note CPU, memory and disk.
3. Disk nearly full? Free space (Windows: Storage settings; Linux: `df -h`).
4. Too many startup programs? Disable unneeded ones (Task Manager > Startup).
5. Restart, then install pending updates.
6. Run a malware scan with the built-in antivirus.
7. If it is an old hard disk (HDD) with constant 100% disk use, an SSD upgrade is the real fix.

Escalate with: what you checked, the numbers you saw, and when it started.

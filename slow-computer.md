# Slow computer

1. ask first: since when? after an update or a new program? everything slow or just one app?
2. open Task Manager (or `top` / `htop` on linux), look at cpu, memory, disk
3. disk almost full? clean it up (`df -h` on linux)
4. too many startup programs - disable the ones you don't need (Task Manager > Startup)
5. restart, install pending updates
6. run an antivirus scan
7. old HDD sitting at 100% disk all the time? honestly the fix is an SSD

When you escalate: say what you checked, the numbers you saw, and when it started.
